**Why this index exists.** `unreviewed/README.md` sat here unlinked for months while being
better than the published `README.md`, and nothing could notice they disagreed. An orphan
document is the defect the rewrite is fixing, so every file added here gets a row.

**It failed once already, on 2026-08-29.** `REPO-CATALOG.md` was added in two commits and neither
added a row here, so the index written to forbid orphans acquired one — and the corrections that
file discovered had no declared path to the documents carrying the claims. Both rows above were
added when `COMPONENTS.md` landed. A rule that does not watch the person applying it is not a rule.
