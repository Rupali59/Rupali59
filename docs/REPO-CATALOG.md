## propagate — CLI + Claude Code plugin
**313 real files** (1,112 tracked, 799 are committed `node_modules` — deliberate: Claude Code does
not `npm install` a marketplace plugin). 218 commits, **100% single-author**. ~64.5k LOC.
- `cli.mjs` 4,390 L, ~20 subcommands; `digest.mjs` 1,413 L
- Domain is two frozen enums: **8 edge states**, **8 dispositions**, strictly validated —
  `wontfix` without a reason throws; `both-reconciled` is the only disposition legal after `DIVERGED`
- **5 hook registrations across 4 hook files** on `SessionStart` and `PreToolUse`
- Pure DAG layer (`lib/graph/graph.mjs`) with **no fs/git/config imports**, so the verify ordering
  guard is provable against synthetic fixtures
- `bin/make-public.mjs` **exits 2 without an identity map**, and CI asserts the *refusal* — "the
  failure mode to prevent is a half-scrubbed publish, not a missing one"
- CI runs a **Node 20/22/24 matrix where 20 is a below-floor probe expected to fail**, plus a
  fresh-machine stranger simulation with an empty `$HOME`
- **142 test files / 1,312 cases**
