  • Agent developer toolchain, deployed system-wide — propagate, a Claude Code plugin published through a marketplace I run and installed at user level, so its hooks execute in every agent session on the machine rather than only where it is checked out. 4 slash commands, 4 hook scripts across 5 registrations on 2 events, 63 library modules, 143 test files.   • Agent guardrail delivered at the moment of risk — a PreToolUse hook that pattern-matches the literal command an agent is about to execute against declared hazards and surfaces the matching one before it runs; written after a documented hazard sitting three files away was hit anyway and cost 11 false verification records. A companion SessionStart hook injects 18 canonical engineering rules into every session, and a restatement detector holds 50 CLAUDE.md files at zero divergent copies.
  • Production LLM classification pipeline, engineered for unreliability — Gemini calls constrained by enforced response schemas, run at temperature: 0 and batched, with determinism resting on cache-on-first-write rather than on the model, and a keyword-classifier fallback so a provider outage degrades quality instead of breaking ingestion. Model-proposed sources are existence-checked against the live API before acceptance, and an inconclusive check returns the candidate flagged rather than asserted.
  • Evaluation harnesses, not vibes — every detector and guardrail trigger ships a selftest asserting it can fire against a known-positive input, because a check that cannot fail reports success; the harness has caught real defects, including a rule whose detector could never have matched its own body. A Claude Cowork job-classification skill is tested against fixtures and a golden set.
  • Human-in-the-loop by construction — no downstream file is ever edited automatically: the tooling finds and explains, a person approves, and each decision is recorded as an append-only ledger event. The background monitor has run 2,420 times with zero runs that could not look — “found nothing” and “looked at nothing” are deliberately different outputs.
